# Sentiment Analysis Using Machine Learning

## Project Overview

This project focuses on analyzing customer reviews and automatically predicting whether a review expresses a **positive** or **negative** sentiment. The system uses Natural Language Processing (NLP) and Machine Learning techniques to process textual data and classify customer feedback accurately.

## Objective

The primary objective of this project is to build a machine learning model capable of understanding customer opinions from text reviews and categorizing them into sentiment classes. This helps organizations analyze customer satisfaction and improve decision-making.

## Features

* Text preprocessing and cleaning
* Feature extraction using TF-IDF Vectorization
* Sentiment classification of customer reviews
* Support for Positive and Negative sentiment prediction
* Performance evaluation using machine learning metrics
* Easy-to-use and scalable workflow

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* TF-IDF Vectorizer
* Machine Learning Algorithms

  * Naive Bayes
  * Support Vector Machine (SVM)

## Dataset

The project uses a customer review dataset stored in CSV format. The dataset contains review text along with sentiment labels used for training and testing the model.

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Text Cleaning
4. Feature Extraction using TF-IDF
5. Model Training
6. Sentiment Prediction
7. Performance Evaluation

## Machine Learning Models

### Naive Bayes

A probabilistic classification algorithm that performs efficiently on text classification tasks.

### Support Vector Machine (SVM)

A powerful supervised learning algorithm used for accurate sentiment classification.

## Results

The trained model successfully classifies customer reviews into:

* Positive Sentiment
* Negative Sentiment

The project demonstrates the effectiveness of Machine Learning and Natural Language Processing techniques in sentiment analysis tasks.
