# Sentiment-Analysis-Project
Sentiment Analysis Project using Machine Learning.

Project Name: Sentiment Analysis Project

Objective:
This project analyzes customer reviews and predicts whether the sentiment is positive or negative.

Technologies Used:
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Naive Bayes
- SVM

Dataset:
Customer review dataset in CSV format.

Result:
The model classifies reviews into positive and negative sentiments.
